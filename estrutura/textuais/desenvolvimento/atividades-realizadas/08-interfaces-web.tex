\section{Desenvolvimento das Interfaces Web}
\label{sec:interfaces-web}

\subsection{Telas Criadas}

Foram desenvolvidas telas específicas para apoiar o fluxo de solicitação, revisão e acompanhamento das mudanças de categoria. Essas interfaces permitiram que usuários e administradores realizassem operações de forma mais organizada, com maior visibilidade do processo e menor dependência de ações manuais externas.

\subsection{Componentes Vue}

Os componentes Vue foram estruturados para reutilização e facilitar a manutenção da interface. A modularização do frontend permitiu separar as responsabilidades de cada parte da aplicação e melhorar a experiência de uso em diferentes etapas do processo de aprovação.

\subsection{Integração frontend/backend}

A integração entre frontend e backend foi planejada para garantir comunicação consistente entre as telas e os serviços responsáveis pelo processamento das solicitações. Essa integração permitiu a atualização dinâmica das informações e o acompanhamento em tempo real do estado das operações.
